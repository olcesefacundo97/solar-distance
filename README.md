# solar-distance

This repository currently contains the default NestJS starter application. The solar-distance feature implied by the repository name has not been implemented.

The current root endpoint returns the starter response `Hello World!`. This repository is not part of my featured portfolio.

## Run locally

Requirements: Node.js and npm.

```bash
npm install
npm run start:dev
```

## Current stack

- NestJS
- TypeScript
- Jest starter test configuration

## Status

Starter scaffold only. No astronomical calculations, external data sources, or solar-distance API are implemented yet.
